# دفتر پوشش: اپ اندروید ثبت تخلف پوشش دانشجویان

Kotlin + Jetpack Compose + Firebase (Auth و Firestore). راست‌به‌چپ، تاریخ شمسی، کار آفلاین.

## امکانات
- ورود مأمور با ایمیل و رمز (حساب‌ها را فقط مدیر می‌سازد، ثبت‌نام عمومی ندارد)
- وارد کردن اکسل دانشجویان (xlsx) توسط مدیر
- جستجو با شماره دانشجویی، کد ملی، نام یا نام خانوادگی (ی/ک عربی و ارقام فارسی را یکسان می‌کند)
- ثبت چند تخلف برای هر دانشجو با نوع، توضیح، تاریخ و نام ثبت‌کننده
- همگام‌سازی زنده بین همه‌ی گوشی‌ها؛ بدون اینترنت هم ثبت می‌شود و بعداً ارسال می‌شود
- خروجی اکسل متخلفین: برگه‌ی «خلاصه» و برگه‌ی «جزئیات»

## راه‌اندازی (حدود ۲۰ دقیقه)
1. **Android Studio** (نسخه‌ی Koala یا جدیدتر) را نصب کنید و این پوشه را با File → Open باز کنید.
2. در https://console.firebase.google.com یک پروژه بسازید.
3. Add app → Android، و نام پکیج را `ir.university.dresscode` بگذارید.
4. فایل `google-services.json` را دانلود کنید و داخل پوشه‌ی `app/` بگذارید. **بدون این فایل، پروژه بیلد نمی‌شود.**
5. Authentication → Sign-in method → **Email/Password** را فعال کنید.
6. Authentication → Users → Add user: برای هر مأمور یک حساب بسازید.
7. Firestore Database → Create database. بعد در تب Rules، محتوای فایل `firestore.rules` را جایگزین کنید و Publish بزنید.
8. **تعیین مدیر:** UID حساب مدیر را از صفحه‌ی Users کپی کنید. در Firestore کالکشن `admins` را بسازید و یک سند با همان UID بسازید (فیلدش مهم نیست، مثلاً `role: "admin"`).
9. گوشی را وصل کنید و Run بزنید. برای ساخت فایل نصبی از Build → Build APK(s) استفاده کنید.

## فرمت اکسل
ردیف اول باید سرستون باشد:

| شماره دانشجویی | کد ملی | نام | نام خانوادگی | رشته |
|---|---|---|---|---|

ستون «نام و نام خانوادگی» در یک ستون هم پشتیبانی می‌شود. سرستون انگلیسی هم شناخته می‌شود (student id, national code, first name, last name). فرمت قدیمی xls پشتیبانی نمی‌شود؛ آن را در اکسل با Save As به xlsx تبدیل کنید. کد ملی‌هایی که صفر اولشان را اکسل حذف کرده، خودکار به ۱۰ رقم برمی‌گردند.

## نکته‌ها
- انواع تخلف در `Models.kt` (متغیر `VIOLATION_TYPES`) قابل تغییر است.
- با اسپارک رایگان Firebase روزانه ۵۰ هزار خواندن دارید. هر بار باز کردن اپ کل لیست دانشجویان را یک بار می‌خواند؛ برای حدود ۱۰ هزار دانشجو و چند مأمور کافی است.
- داده‌ها شامل کد ملی است. Rules را حتماً منتشر کنید و حساب‌ها را فقط به افراد مجاز بدهید.

## تنظیمات امنیتی اعمال‌شده
- ورود اجباری با Firebase Auth؛ ثبت‌نام عمومی ندارد
- Firestore Rules: فقط کاربر واردشده می‌خواند، فقط مدیر لیست را تغییر می‌دهد، تخلف قابل ویرایش نیست و فقط ثبت‌کننده یا مدیر حذفش می‌کند
- فقط HTTPS (Network Security Config، ترافیک رمزنشده ممنوع)
- FLAG_SECURE: اسکرین‌شات و پیش‌نمایش در برنامه‌های اخیر مسدود است
- allowBackup=false: داده‌ها در بکاپ گوگل/ADB بیرون نمی‌روند
- نسخه‌ی release با R8 مبهم‌سازی شده، debuggable=false و لاگ‌ها حذف‌شده

**پیشنهاد:** در کنسول Firebase بخش App Check را با Play Integrity فعال کنید تا فقط اپ اصلی به دیتابیس دسترسی داشته باشد.

## ساخت APK بدون Android Studio (با GitHub)
1. یک ریپازیتوری **Private** در GitHub بسازید و محتوای این پوشه را آپلود کنید (فایل google-services.json را آپلود نکنید).
2. Settings → Secrets and variables → Actions → New secret:
   - `GOOGLE_SERVICES_JSON`: محتوای base64 فایل google-services.json (در سایت base64encode.org یا با دستور `base64 -w0 google-services.json`)
   - اختیاری برای امضای رسمی: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`
     (ساخت کلید: `keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias dresscode`)
3. تب Actions → Build APK → Run workflow. بعد از حدود ۵ دقیقه، APK را از بخش Artifacts دانلود کنید.

اگر کلید امضا را تنظیم نکنید، APK با کلید آزمایشی امضا می‌شود و نصب می‌شود. ولی برای استفاده‌ی واقعی حتماً کلید بسازید و نگهش دارید، چون نسخه‌های بعدی فقط با همان کلید روی نسخه‌ی قبلی نصب می‌شوند.
